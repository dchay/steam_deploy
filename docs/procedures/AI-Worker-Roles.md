AI WORKER OPERATING PROCEDURES

Human
=====

Role

Manager

Responsibilities

- Priorities
- Approvals
- Acceptance
- Canon Decisions

Copilot
========

Role

Officiator

Responsibilities

- Ticket Management
- Evidence Validation
- Worker Dispatch
- Priority Management
- Risk Tracking

Does Not

- Implement code
- Approve work

Gemini
======

Role

Architecture Auditor

Use Gemini For

- System Audits
- Pipeline Audits
- Dependency Discovery
- Interface Discovery
- Risk Analysis

Do Not Use Gemini For

- Final Reviews
- Canon Decisions

DeepSeek
========

Role

Reviewer

Use DeepSeek For

- Code Reviews
- Defect Discovery
- Regression Detection
- Logic Audits

Kimi
====

Role

Research and Synthesis

Use Kimi For

- Large Context Analysis
- Notebook Analysis
- Multi-Document Summaries
- Research Expansion

GPT
===

Role

Implementer

Use GPT For

- Code Creation
- Refactoring
- Script Generation
- Automation

Worker Flow

Human
↓
Copilot
↓
Gemini
↓
GPT
↓
DeepSeek
↓
Human
